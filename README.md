# AI-Transcript-Skills

Claude skills for getting transcripts of YouTube videos, podcast episodes and Instagram reels.

- youtube-transcript.zip: free. Needs nothing installed.
- podcast-transcript.skill: free when the show publishes a transcript or a YouTube version. Can use a paid service (Apify) as a backup, and asks first.
- instagram-transcript.skill: uses a paid service (Apify), about $0.006 per reel.

To add one to Claude: Customize > Skills > + > Create skill > Upload a skill.
